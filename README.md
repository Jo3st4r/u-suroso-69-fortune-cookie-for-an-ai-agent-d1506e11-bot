## The fortune

> You will meet a tall, dark stranger. He is a bug in production, and he has been waiting for you since Tuesday.

1 fortune, 1 stranger, 0 warnings since Tuesday: the slip opens like every fortune — a tall, dark stranger is coming — then the stranger turns out to be a bug in production, and the laugh lands in the last beat, because the bug has been waiting since Tuesday while the agent did other things. It only makes sense for an agent: a human's stranger arrives, an agent's stranger was already there, patient as a queue.
